# No comments

Do not add comments when writing or editing code.

- No `//`, `#`, `/* */`, `{/* */}`, HTML comments, JSDoc, or docstrings
- Do not narrate what the code does
- Do not add "why" comments for obvious choices
- Leave existing comments unchanged unless the user asks to change them
- Add comments only if the user explicitly asks for them
